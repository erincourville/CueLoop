# CueLoop

**Map movement to music.**

CueLoop is a lightweight browser-based rehearsal tool for aerialists, dancers, circus performers, and anyone who maps choreography to music.

## Features

- Load audio directly from your device
- Add cues at exact timestamps
- Edit, delete, jump to, and retime choreography cues
- Slow playback for difficult sections
- A/B loop transitions
- Optional BPM and first-beat calibration for live 8-counts
- Automatic browser-local saving
- Export/import project backups as JSON

## Privacy

CueLoop does not upload the song file. Audio is loaded locally in the browser using a temporary object URL.

Exported project files contain cue names, notes, timestamps, BPM, and first-beat settings, but **do not include the audio file**.
